02

Industrial PCB Defect Detection System — Smart India Hackathon

Engineered and fine-tuned a custom YOLOv8 computer vision model to identify 6 unique classes of PCB micro-defects for industrial quality assurance. Designed a programmatic synthetic data pipeline using Albumentations with physics-based distortions, scaling the training set by 200+ target-domain images. Mitigated catastrophic forgetting during cloud fine-tuning with a balanced 50/50 mix of simulated and original clean data and maintained an 80/20 train/validation split across 300+ image-label pairs. Achieved 76.0% mAP50 and 99.5% precision on high-complexity spurious-copper anomalies, then deployed a real-time Streamlit dashboard.

YOLOv8 Computer Vision Albumentations Streamlit
